Drive Minimal HUD is a modern, minimalist and fully customizable vehicle HUD designed to stay clean and discreet on screen.

Features:

Speedometer and current gear
RPM display
Fuel level ⛽
Automatic electric vehicle detection with battery indicator 🔋
Engine temperature
Speed limiter with ON/OFF control
INSERT key to open Edit Mode
Drag & drop HUD positioning
Mouse resizing
Show/hide HUD option
Reset button
Position, size and visibility saved using KVP
Smooth slide animation when entering or leaving a vehicle
